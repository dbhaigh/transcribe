# Synthetic fixtures

The checked-in WAV fixtures are generated by `generate_samples.py` from
deterministic sine waves with light harmonic content and short note envelopes.
They are intentionally simple and are not real-world recordings or accuracy
benchmarks. Expected pitch lists are provided beside each fixture.

For recorded guitar audio and annotations, the public [GuitarSet
dataset](https://doi.org/10.5281/zenodo.3371780) is licensed CC BY 4.0
(Qingyang Xi et al., ISMIR 2018). The full mono-microphone archive is about
657 MB; no excerpt is redistributed here. Download the archive from Zenodo
and follow its attribution terms before adding any derived recording to this
repository.

Regenerate with Python 3:

```powershell
python .\samples\generate_samples.py
```
